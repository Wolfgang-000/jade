# 澄和健康 · 医药健康商城微信小程序

这是在原“C端营销活动小程序”基础上重构的完整商业高保真原型。

## 当前能力
- 32个核心页面全部纳入 app.json
- 首页 / 搜索 / 分类 / 商品详情 / 规格 / 购物袋 / 结算 / 支付 / 订单 / 物流
- 会员中心 / 我的 / 收藏 / 浏览 / 优惠券 / 积分 / 地址
- 客服 / 药师咨询 / 品牌馆 / 活动中心 / 活动详情 / 健康内容
- 隐私 / 协议 / 产品说明 / 售后
- 本地Mock商品数据
- localStorage购物袋、收藏、浏览记录
- OTC / 医疗器械 / 营养健康 / 普通健康商品 / Rx流程示意
- 完整暖白、中性、高端零售向 Design System

## 导入
微信开发者工具直接打开本目录：
`C端营销活动小程序_完整版`

项目配置已经设置：
`miniprogramRoot: miniprogram/`

## 开发方式
后续不再反复下载ZIP。
ChatGPT直接修改GitHub源码；本地Git Pull后，微信开发者工具自动重新编译。

## 重要说明
当前是高保真可交互原型，不是生产后端。
正式上线前需要接入真实：
- AppID / 微信登录
- 商品、库存、价格、会员、优惠、订单API
- 微信支付
- 微信地址
- 小程序码
- 订阅消息
- 客服与药师工作台
- 合规/处方/资格规则
- 真实品牌图片和商品图片
- 埋点、监控、异常状态服务端支持

详细设计见 `docs/PRODUCT_DESIGN_SPEC.md`。
