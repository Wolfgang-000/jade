
# 正式投入使用清单

## 账号与主体
- 微信公众平台注册小程序，主体建议使用公司主体。
- 完成小程序备案及微信要求的主体认证/资质流程。
- 医药健康内容按实际业务确认药品信息、广告、经营相关资质与展示要求。

## 技术配置
- 正式 AppID
- API HTTPS 域名
- request 合法域名
- 如使用 H5 商城：配置 web-view 业务域名
- 如跳转已有商城小程序：填写目标 AppID 和对应商品 path
- 隐私保护指引
- 用户隐私接口声明
- 客服信息
- 小程序码生成服务

## CMS 后台
- 账号登录和角色权限
- 运营 / 合规审核角色分离
- 图片对象存储
- 数据库
- 发布/下线审计日志
- 外链校验
- 合规发布拦截

## 发布流程
CMS创建活动 → 内部合规复核 → 发布 → API生效 → 生成小程序码 → 微信群/公众号/海报投放 → 数据中心看UV/点击/商城跳转。
