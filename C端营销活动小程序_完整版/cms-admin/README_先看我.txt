二、设计方向
后台：
- 中性SaaS设计
- 高信息效率
- 单一主CTA
- 弱装饰
- 少卡片、少阴影、少高饱和色
- 活动编辑通过 Tab + Drawer 降低认知负担

消费者前台：
- 暖白 + 深红 + 少量金色
- 利益点 → 主推商品 → 更多商品 → 信任 → CTA
- 不照搬任何品牌页面，仅借鉴高端珠宝品牌常见的红金、留白、克制质感

三、如何打开
直接双击 index.html 即可在浏览器运行。

四、重要说明
这是“高保真可交互前端原型”，不是生产后端系统。
真实上线仍需补充：
- 登录与权限
- 数据库
- 对象存储
- 正式二维码
- 域名/HTTPS
- 埋点服务
- CMS API
- 生产环境合规策略
- 与现有商城的订单/归因回传（如有）

五、核心验收方式
不要看“是不是够花哨”，而是直接测试：
1. 新建活动
