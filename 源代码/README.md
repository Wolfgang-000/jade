# 御翠珠宝 - 翡翠珠宝商城

## 项目简介

本项目包含两个版本：
1. **Web版本** - 当前已完成的HTML/CSS/JavaScript版本
2. **微信小程序版本** - 可直接发布到微信小程序平台的版本

## 微信小程序版本发布指南

### 前置准备

1. **注册微信小程序账号**
   - 访问 https://mp.weixin.qq.com/
   - 注册小程序账号（个人或企业）
   - 完成微信认证

2. **获取AppID**
   - 登录微信公众平台
   - 在「开发」→「开发管理」→「开发设置」中获取AppID

### 微信小程序项目结构

```
jade-miniprogram/
├── pages/                  # 页面目录
│   ├── index/             # 首页
│   ├── products/          # 商品列表
│   ├── product-detail/    # 商品详情
│   ├── cart/              # 购物车
│   ├── checkout/          # 结算
│   ├── orders/            # 订单
│   ├── profile/           # 个人中心
│   ├── login/             # 登录
│   └── favorites/         # 收藏夹
├── utils/                 # 工具函数
├── components/            # 自定义组件
├── images/                # 图片资源
├── app.js                 # 小程序逻辑
├── app.json               # 小程序配置
├── app.wxss               # 全局样式
└── project.config.json    # 项目配置
```

### 发布流程

#### 第一步：下载微信开发者工具
1. 访问 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 下载并安装微信开发者工具

#### 第二步：创建小程序项目
1. 打开微信开发者工具
2. 选择「小程序」
3. 填写项目信息：
   - 项目名称：御翠珠宝
   - 目录：选择项目目录
   - AppID：填入您的AppID
   - 开发模式：小程序
   - 后端服务：不使用云服务

#### 第三步：完善小程序信息
在微信公众平台（https://mp.weixin.qq.com/）完善以下信息：
- 小程序名称
- 小程序头像
- 小程序介绍
- 服务类目
- 标签

#### 第四步：代码审核与发布
1. 在微信开发者工具中点击「上传」
2. 填写版本号和项目备注
3. 登录微信公众平台
4. 进入「版本管理」→「开发版本」
5. 提交审核
6. 等待审核通过（通常1-7个工作日）
7. 审核通过后点击「发布」

## 方案二：Web版本作为H5页面嵌入微信小程序

如果您不想重新开发，可以将当前的Web版本作为H5页面嵌入微信小程序：

### 实现步骤

1. 创建一个简单的微信小程序
2. 使用 `web-view` 组件加载Web版本
3. 配置业务域名（需要HTTPS）

### 代码示例

```xml
<!-- pages/index/index.wxml -->
<web-view src="https://your-domain.com/index.html"></web-view>
```

### 注意事项
- 需要配置HTTPS服务器
- 需要在微信公众平台配置业务域名
- 部分微信小程序API无法在web-view中使用
